## 👩‍💻 About Me

I'm a full-stack developer with a B.Sc. in Computer and Systems Engineering from **Ain Shams University**. I build web applications with **React, Next.js, Node.js, Express, and MongoDB**, and I care about the parts that make an app trustworthy: validating data on the server, keeping inventory consistent, and handling payments securely.

My flagship project, **StringTopia**, is a live e-commerce platform with Paymob payment integration, server-side pricing validation, and atomic inventory updates. I also have three years of experience teaching programming and computer science, which taught me to explain technical ideas clearly and to write code other people can follow.

- 🔭 **Currently working on:** polishing and extending StringTopia
- 🌱 **Currently learning:** TypeScript, automated testing, and Docker / CI-CD
- 💬 **Ask me about:** MERN stack apps, REST APIs, payment integration, real-time apps with Socket.IO
- 🤝 **Open to:** junior full-stack roles, internships, and open-source collaboration
